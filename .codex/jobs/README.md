# Jobs

This directory marks the boundary for concrete job experience in a deployed Seed.

The generic public repository does not ship Hadosh Academy's website jobs, client jobs, or another user's private work history as canonical cognition. Reusable rules for how jobs behave belong in the harness; particular objectives, interactions, plans, artifacts, outcomes, and accumulated experience belong to the user/deployment.

The Codex job schema and lifecycle have not been defined yet.
