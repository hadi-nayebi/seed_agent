# Seed context index

This directory defines shared architectural language before implementation makes accidental standards.

## Current contracts

- [`architecture.md`](architecture.md) — repository identity, implementation lineage, layer boundaries, instruction/working-memory separation, and current non-decisions.

## Context discipline

A context document may define a target design before code exists, but it must label implementation status accurately. Historical prototype behavior is evidence; it becomes Codex Seed behavior only after this repository adopts and implements a replacement contract.

Add a new context file only when a capability study has enough evidence to justify a coherent shared vocabulary. Do not create speculative files for every historical plugin in advance.
